# ACR vs OSS 说明

## 关键区别

### ACR（容器镜像服务）
- **用途**：专门存储和管理 **Docker 镜像**
- **格式**：符合 Docker 镜像规范（包含 manifest、layers 等）
- **功能**：支持镜像版本管理、安全扫描、自动构建等
- **FC 支持**：✅ 函数计算可以直接从 ACR 拉取镜像

### OSS（对象存储服务）
- **用途**：通用对象存储，可以存储 **任何文件**
- **格式**：普通文件存储（不能直接作为容器镜像仓库）
- **功能**：文件上传、下载、CDN 加速等
- **FC 支持**：❌ 函数计算**不能**直接从 OSS 拉取 Docker 镜像

## 为什么需要 ACR？

函数计算的 **Custom Container** 功能需要从**容器镜像仓库**拉取镜像，而不是从普通文件存储。

### FC 支持的镜像仓库类型：
1. ✅ **ACR（阿里云容器镜像服务）** - 推荐，国内访问快
2. ✅ **Docker Hub** - 可用，但国内访问可能慢
3. ✅ **其他容器镜像仓库**（如 Harbor、私有仓库等）

### FC 不支持的：
- ❌ OSS（对象存储）
- ❌ 普通文件服务器

## OSS 的用途（在部署中）

虽然 OSS 不能存储 Docker 镜像，但可以用于：

### 1. 存储 AI 模型文件
在部署指南中提到的"使用 OSS 存储模型"是指：
- 将 AI 模型文件（如 OCR 模型、检测模型等）上传到 OSS
- 函数启动时从 OSS 下载模型文件
- 这样可以减小 Docker 镜像大小

### 2. 存储翻译结果
- 翻译后的图片可以上传到 OSS
- 通过 CDN 加速访问

## 替代方案

如果您不想使用 ACR，可以考虑：

### 方案1：使用 Docker Hub（免费）

**优点**：
- 免费
- 不需要额外开通服务

**缺点**：
- 国内访问可能较慢
- 公开仓库有流量限制

**步骤**：
```bash
# 1. 登录 Docker Hub
docker login

# 2. 标记镜像
docker tag manga-image-translator:fc your-dockerhub-username/manga-image-translator:fc

# 3. 推送镜像
docker push your-dockerhub-username/manga-image-translator:fc

# 4. 在 FC 中使用镜像地址
# docker.io/your-dockerhub-username/manga-image-translator:fc
```

### 方案2：使用 ACR（推荐）

**优点**：
- ✅ 与 FC 同属阿里云，集成好
- ✅ 国内访问速度快
- ✅ 个人版免费
- ✅ 支持私有仓库

**缺点**：
- 需要开通服务（但免费）

## 成本对比

### ACR 个人版
- **免费额度**：每月 500MB 存储空间
- **超出后**：¥0.1/GB/月
- **流量**：免费（内网流量）

### Docker Hub
- **免费**：公开仓库
- **限制**：每月 200 次拉取（6 小时内的重复拉取不计）

## 推荐方案

### 早期验证阶段：使用 ACR 个人版
- ✅ 免费额度足够使用
- ✅ 国内访问速度快
- ✅ 与 FC 集成好

### 如果不想用 ACR：使用 Docker Hub
- ✅ 完全免费
- ⚠️ 国内访问可能慢
- ⚠️ 需要公开仓库（或付费私有仓库）

## 总结

**问题**：是否一定需要 ACR？

**答案**：
- ❌ **不一定**，可以使用 Docker Hub 或其他容器镜像仓库
- ✅ **但推荐使用 ACR**，因为：
  1. 个人版免费
  2. 国内访问速度快
  3. 与 FC 集成好
  4. 支持私有仓库

**OSS 不能替代 ACR**，因为：
- OSS 是对象存储，不是容器镜像仓库
- FC 需要从容器镜像仓库拉取镜像
- 但 OSS 可以用来存储模型文件（减小镜像大小）
