# FC更多配置项说明

## 配置项说明

### 1. 资源组

**是否需要配置？** ⭕ **可选**（保持默认即可）

**说明：**
- 用于资源管理和分组
- 默认资源组即可
- 如果需要资源分组管理，可以创建新的资源组

**建议：** 保持默认（"默认资源组"）

### 2. 标签

**是否需要配置？** ⭕ **可选**（可以不填写）

**说明：**
- 用于资源标记和分类
- 最多可以设置20个标签
- 标签由键值对组成

**建议：** 可以不填写（留空）

**如果想填写，建议：**
- 标签键：`Project`
- 标签值：`manga-translator`

### 3. 时区

**是否需要配置？** ⭕ **可选**（保持默认UTC即可）

**说明：**
- 函数运行环境的时区
- 默认：UTC
- 可以通过环境变量TZ修改

**建议：** 保持默认（UTC）

**如果需要中国时区：**
- 选择：`Asia/Shanghai`
- 或者通过环境变量设置：`TZ=Asia/Shanghai`

### 4. 环境变量 ⚠️ **必须配置**

**是否需要配置？** ✅ **必须配置**

**说明：**
- 用于配置函数运行时的环境变量
- 我们的服务需要DeepSeek API密钥等配置

**必须添加的环境变量：**

| 变量名 | 变量值 | 说明 |
|--------|--------|------|
| `DEEPSEEK_API_KEY` | `sk-fa51105a356949fa91dc262b7eea2aa6` | DeepSeek API密钥 |
| `DEEPSEEK_API_BASE` | `https://api.deepseek.com` | DeepSeek API地址 |
| `DEEPSEEK_MODEL` | `deepseek-chat` | DeepSeek模型名称 |
| `PYTHONUNBUFFERED` | `1` | Python输出不缓冲 |

**操作步骤：**
1. 点击 **"+ 添加变量"** 按钮
2. 依次添加上述4个环境变量
3. 确保变量名和变量值正确

### 5. 延时释放弹性实例

**是否需要开启？** ❌ **不需要开启**（保持关闭）

**说明：**
- 用于有后台任务的场景（如异步日志采集）
- 开启后，实例处理完请求后不立刻释放
- 需要承担少量费用

**我们的服务：**
- 每个翻译请求是同步处理的
- 处理完成后立即返回结果
- 没有后台任务
- 不需要延时释放

**建议：** ❌ **不勾选**（保持关闭）
