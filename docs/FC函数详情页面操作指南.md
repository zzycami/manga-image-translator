# FC函数详情页面操作指南

## 当前状态

从函数详情页面看到：
- ✅ 函数已创建成功
- ✅ HTTP触发器已创建（defaultTrigger）
- ⏳ 镜像资源准备中（Image resource preparing）

## 下一步操作

### 步骤1：等待镜像资源准备完成

**当前状态：** "镜像资源准备中"（Image resource preparing）

**需要等待：**
- 镜像从ACR拉取到FC
- 镜像解压和准备
- 通常需要几分钟时间

**如何确认准备完成：**
1. 刷新页面
2. 查看镜像状态是否变为"正常"或"就绪"
3. 或者尝试测试函数

### 步骤2：查看触发器获取访问地址

#### 方法1：在函数拓扑图中查看

1. 在函数拓扑图中，找到 **"Trigger: defaultTrigger"**
2. 点击触发器
3. 查看触发器的详细信息
4. 记录HTTP触发器的访问地址

#### 方法2：在触发器标签页查看

1. 点击顶部标签 **"触发器"**（Trigger）
2. 找到 **"defaultTrigger"**
3. 查看触发器的详细信息
4. 记录HTTP触发器的访问地址

**访问地址格式类似：**
```
https://manga-translator-xxxxx.cn-hangzhou.fcapp.run
```

### 步骤3：测试函数

#### 方法1：使用FC控制台的测试功能

1. 点击顶部标签 **"测试"**（Test）
2. 选择测试模板或创建自定义测试
3. 配置测试请求
4. 点击 **"测试"** 按钮
5. 查看测试结果

#### 方法2：使用curl命令测试

**健康检查：**
```bash
curl https://your-function-url/health
```

**根路径测试：**
```bash
curl https://your-function-url/
```

**翻译功能测试：**
```bash
curl -X POST https://your-function-url/translate \
  -H "Content-Type: application/json" \
  -d '{
    "image_url": "https://example.com/image.jpg",
    "config": {
      "translator": {"translator": "deepseek"},
      "translator": {"target_lang": "CHS"}
    },
    "env": {
      "DEEPSEEK_API_KEY": "sk-fa51105a356949fa91dc262b7eea2aa6"
    }
  }'
```

### 步骤4：查看日志

1. 点击顶部标签 **"日志"**（Log）
2. 查看函数执行日志
3. 检查是否有错误信息
4. 查看函数调用情况

### 步骤5：查看监控

1. 点击顶部标签 **"监控"**（Monitoring）
2. 查看函数调用次数
3. 查看执行时间
4. 查看错误率

## 常见问题

### Q1: 镜像一直显示"准备中"

**可能原因：**
- 镜像较大，需要较长时间
- 网络问题

**解决方法：**
- 等待几分钟
- 刷新页面
- 查看日志是否有错误

### Q2: 如何获取函数访问地址？

**方法：**
1. 点击 **"触发器"** 标签
2. 找到HTTP触发器
3. 查看访问地址

### Q3: 函数调用失败

**可能原因：**
- 镜像未准备完成
- 配置错误
- 代码错误

**解决方法：**
1. 查看日志
2. 检查配置
3. 检查环境变量
