# FC地域选择说明

## 如何选择地域

### 方法1：顶部导航栏（最常用）
1. 在控制台顶部导航栏右侧
2. 找到显示 **"Global"（全球）** 或当前地域名称的下拉菜单
3. 点击下拉菜单
4. 选择目标地域

### 方法2：资源使用统计区域
1. 在"资源使用统计"标题旁边
2. 找到显示 **"全部地域"** 的下拉菜单
3. 点击选择具体地域

## 推荐地域选择

### ✅ 推荐：华东1（杭州）`cn-hangzhou`

**原因：**
- 与ACR仓库地域一致（`manga-translator-registry.cn-hangzhou.cr.aliyuncs.com`）
- 减少跨地域访问延迟
- 降低数据传输成本
- 提高镜像拉取速度

### 其他可选地域
- 华东2（上海）`cn-shanghai`
- 华北2（北京）`cn-beijing`
- 华南1（深圳）`cn-shenzhen`

## 重要提示

⚠️ **地域选择后，所有资源（服务、函数）都会在该地域下创建**

- 如果选错了地域，需要重新选择并创建资源
- 不同地域的资源无法直接互通
- 建议在创建服务前就确定好地域

## 下一步

选择好地域后：
1. 点击左侧菜单 **函数管理** → **函数列表**
2. 创建服务（如果还没有）
3. 创建函数
