## 构建完成后的步骤

### 步骤1：验证镜像构建成功
```bash
docker images | grep manga-image-translator:fc-optimized
```

应该看到类似输出：
```
manga-image-translator   fc-optimized   <image-id>   <time>   15GB
```

### 步骤2：标记镜像为ACR格式
```bash
docker tag manga-image-translator:fc-optimized \
  manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc
```

### 步骤3：登录ACR
```bash
docker login --username=zzycami@foxmail.com manga-translator-registry.cn-hangzhou.cr.aliyuncs.com
```

**密码位置**：ACR控制台 → 访问凭证 → 设置固定密码

### 步骤4：推送镜像到ACR
```bash
# 注意：需要设置代理（如果网络需要）
export https_proxy=http://127.0.0.1:7890
export http_proxy=http://127.0.0.1:7890
export all_proxy=socks5://127.0.0.1:7890

docker push manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc
```

**预计时间**：20-60分钟（镜像约15GB）

### 步骤5：在FC中创建函数

1. 登录阿里云控制台
2. 进入 **函数计算（FC）** 服务
3. 创建函数，选择 **自定义容器**
4. 配置信息：
   - **镜像地址**：`manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc`
   - **端口**：`9000`
   - **内存**：建议 `8192MB`（8GB）或更高
   - **GPU**：选择GPU实例（如果需要）
   - **超时时间**：`600秒`（10分钟）
   - **环境变量**：
     - `DEEPSEEK_API_KEY`: 您的DeepSeek API密钥
     - `DEEPSEEK_API_BASE`: `https://api.deepseek.com`
     - `DEEPSEEK_MODEL`: `deepseek-chat`

## 常见问题

### Q: 构建失败怎么办？
**A:** 
1. 检查代理是否正常工作
2. 查看错误日志：`tail -50 /tmp/docker-build.log`
3. 重新运行：`./build_with_proxy.sh`

### Q: 推送镜像很慢？
**A:** 
- 这是正常的，15GB镜像需要时间
- 确保代理设置正确
- 可以尝试使用阿里云内网（如果在ECS上）

### Q: 如何确认构建完成？
**A:** 
运行 `docker images | grep manga-image-translator:fc-optimized`，如果看到镜像且大小约15GB，说明构建成功。
