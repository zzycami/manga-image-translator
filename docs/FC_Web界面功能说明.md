# FC Web界面功能说明

## ✅ 当前支持的Web功能

### 1. Web管理界面

**访问地址：**
```
https://manga-tanslator-pssdhxnbcm.cn-hangzhou.fcapp.run/
```

**功能：**
- ✅ 服务状态查看
- ✅ API端点列表
- ✅ 缓存文件管理
  - 查看结果列表
  - 删除指定结果
  - 清空所有缓存

**说明：**
- 这是一个**管理界面**，不是完整的翻译界面
- 主要用于查看状态和管理缓存文件
- 不包含图片上传和翻译功能（使用API接口）

### 2. API信息接口

**访问地址：**
```
https://manga-tanslator-pssdhxnbcm.cn-hangzhou.fcapp.run/api
```

**返回：** JSON格式的API端点列表

## 📋 完整翻译Web界面

如果您需要完整的翻译Web界面（像本地server/main.py那样），需要：

1. **添加完整的HTML界面**（包含图片上传、翻译等功能）
2. **添加更多API端点**（支持Web前端调用）
3. **可能需要更多资源**

## 🎯 当前Web界面功能

### 可以做什么：

1. **查看服务状态**
   - 服务是否运行
   - 服务地址
   - 版本信息

2. **查看API端点**
   - 所有可用的API接口
   - 请求方法和路径

3. **管理缓存文件**
   - 查看翻译结果列表
   - 删除指定的结果文件
   - 清空所有缓存

### 不能做什么：

1. ❌ 上传图片进行翻译（需要使用API接口）
2. ❌ 实时查看翻译进度（需要使用API接口）
3. ❌ 预览翻译结果（需要使用API接口）

## 💡 使用建议

### 对于翻译功能：

- **使用Kotlin后端**：通过API调用翻译服务
- **使用API接口**：直接调用 `/translate/with-form/image/stream` 接口

### 对于管理功能：

- **使用Web界面**：访问 `/` 查看状态和管理缓存
- **使用API接口**：调用 `/status`、`/results/list` 等接口

**翻译功能：**
