# ACR 企业版配置建议（早期验证）

## 配置建议

### 实例名称
```
manga-translator
```
或者您喜欢的名称，如：`manga-translator-dev`、`comic-translator` 等

### 仓库配额
**建议：保持默认 0**

**说明**：
- 基础版默认已包含 **1000 个仓库配额**
- 早期验证只需要 **1 个仓库**（`manga-image-translator`）
- 1000 个配额完全足够，无需额外购买
- 如果后续需要更多仓库，再按需增加

### 命名空间配额
**建议：保持默认 0**

**说明**：
- 基础版默认已包含 **15 个命名空间配额**
- 早期验证只需要 **1 个命名空间**（如：`manga-translator`）
- 15 个配额完全足够，无需额外购买
- 如果后续需要更多命名空间，再按需增加

### VPC 访问控制配额
**建议：保持默认 0**

**说明**：
- VPC 访问控制用于让 VPC 专有网络内的服务拉取镜像
- **函数计算（FC）通常不需要 VPC 访问控制**，因为：
  - FC 可以直接通过公网访问 ACR
  - 如果 FC 和 ACR 在同一区域，可以使用内网访问（免费）
  - 早期验证阶段，公网访问即可
- 如果后续需要 VPC 访问，再按需配置

## 最终配置

| **实例名称** | `manga-translator` | 您喜欢的名称 |
| **仓库配额** | `0` | 基础版已包含 1000 个，足够使用 |
| **命名空间配额** | `0` | 基础版已包含 15 个，足够使用 |
| **VPC 访问控制配额** | `0` | 早期验证不需要，FC 可直接访问 |
