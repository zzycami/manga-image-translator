# 推送完成后的步骤

## ✅ 当前状态

- ✅ 镜像构建完成
- ✅ 镜像已标记为 `fc-v3`
- ⏳ 正在推送到ACR...

## 📋 推送完成后的步骤

### 步骤1：在FC中更新镜像

1. 登录阿里云控制台
2. 进入 **函数计算（FC）** 服务
3. 找到函数：`manga-translator`
4. 点击函数名称进入详情页面
5. 点击 **"配置"**（Configuration）标签
6. 找到 **"修改镜像"** 或 **"镜像地址"**
7. 更新镜像地址为：
   ```
   manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc-v3
   ```
8. 或者只更新Tag为：`fc-v3`
9. 点击 **"保存"** 或 **"更新"**

### 步骤2：等待镜像更新生效

- 等待几分钟让新镜像生效
- 或重新部署函数

### 步骤3：测试新功能

#### 测试Web UI界面

访问：
```
https://manga-tanslator-pssdhxnbcm.cn-hangzhou.fcapp.run/
```

应该能看到Web管理界面，包括：
- 服务状态
- API端点列表
- 缓存管理功能

#### 测试状态接口

```bash
curl https://manga-tanslator-pssdhxnbcm.cn-hangzhou.fcapp.run/status
```

#### 测试结果列表

```bash
curl https://manga-tanslator-pssdhxnbcm.cn-hangzhou.fcapp.run/results/list
```

#### 测试流式翻译

使用Kotlin后端测试，或使用curl：

```bash
curl -X POST https://manga-tanslator-pssdhxnbcm.cn-hangzhou.fcapp.run/translate/with-form/image/stream \
  -F "image=@test.png" \
  -F 'config={"translator":{"translator":"deepseek","target_lang":"CHS"}}'
```

## 🎉 新功能

更新后的FC函数支持：

1. **流式翻译接口**
   - `/translate/with-form/image/stream` - 兼容Kotlin后端

2. **Web UI管理界面**
   - `/` - Web管理界面
   - 查看服务状态
   - 管理缓存文件

3. **状态和缓存管理**
   - `/status` - 获取服务状态
   - `/results/list` - 列出结果
   - `/results/clear` - 清空缓存
   - `/results/{folder_name}` - 删除指定结果

## 📝 注意事项

1. **推送时间**：推送可能需要5-20分钟（取决于镜像大小和网络）
2. **镜像更新**：在FC中更新镜像后，需要等待几分钟生效
3. **缓存文件**：FC环境使用 `/tmp/result` 目录，容器重启后会丢失
