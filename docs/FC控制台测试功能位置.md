# FC控制台测试功能位置

## 当前页面位置

您当前应该在函数详情页面，可以看到：
- 函数拓扑图
- 多个标签页：代码、测试、配置、触发器、日志等

## 测试功能位置

### 方法1：使用"测试"标签（推荐）

1. **在函数详情页面顶部**
2. 找到标签栏，点击 **"测试"**（Test）标签
3. 在测试页面：
   - 选择HTTP方法（GET、POST等）
   - 填写路径（如 `/health`）
   - 填写请求体（如果是POST）
   - 点击 **"测试"** 按钮

### 方法2：使用函数拓扑图

1. 在函数拓扑图中
2. 找到 **"测试函数"** 按钮（通常在右上角）
3. 点击进入测试页面

## 详细操作步骤

### 步骤1：进入测试页面

1. 在函数详情页面
2. 点击顶部标签栏的 **"测试"**（Test）标签
3. 进入测试页面

### 步骤2：配置测试请求

**测试健康检查：**
1. **HTTP方法**：选择 **GET**
2. **路径**：填写 `/health`
3. **请求头**：可以留空
4. **请求体**：留空（GET请求不需要）
5. 点击 **"测试"** 按钮

**测试根路径：**
1. **HTTP方法**：选择 **GET**
2. **路径**：填写 `/`
3. 点击 **"测试"** 按钮

**测试翻译功能：**
1. **HTTP方法**：选择 **POST**
2. **路径**：填写 `/translate`
3. **请求体**：填写JSON：
```json
{
  "image_url": "https://example.com/image.jpg",
  "config": {
    "translator": {"translator": "deepseek"},
    "translator": {"target_lang": "CHS"}
  },
  "env": {
    "DEEPSEEK_API_KEY": "sk-fa51105a356949fa91dc262b7eea2aa6"
  }
}
```
4. 点击 **"测试"** 按钮

### 步骤3：查看测试结果

测试后，会显示：
- 响应状态码
- 响应体
- 执行时间
- 日志信息

## 如果找不到"测试"标签

### 检查位置

1. **函数详情页面顶部**：应该有多个标签
2. **标签顺序**：代码、测试、配置、触发器、日志等
3. **如果看不到**：可能需要滚动标签栏

### 替代方法：使用curl命令

如果找不到测试功能，可以使用curl命令：

```bash
# 获取函数访问地址（从触发器标签页）
# 然后使用curl测试

# 健康检查
curl https://your-function-url/health

# 根路径
curl https://your-function-url/
```

2. **选择GET方法，路径填写 `/health`**
3. **点击"测试"按钮**
