# Docker镜像构建进度监控

## 当前状态

✅ **构建已开始**

Docker构建命令正在后台运行，日志保存在：`/tmp/docker-build.log`

## 监控构建进度

### 方法1：查看构建日志

```bash
tail -f /tmp/docker-build.log
```

### 方法2：查看Docker进程

```bash
docker ps -a | grep build
```

### 方法3：查看镜像构建状态

```bash
docker images | grep manga-image-translator
```

## 构建完成后

构建完成后，需要执行以下步骤：

### 步骤1：标记镜像

```bash
docker tag manga-image-translator:fc-optimized \
  manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc-v3
```

### 步骤2：推送镜像到ACR

```bash
docker push manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc-v3
```

### 步骤3：在FC中更新镜像

1. 在FC函数详情页面
2. 点击 **"配置"**（Configuration）标签
3. 找到 **"修改镜像"** 或 **"镜像地址"**
4. 更新镜像Tag为：`fc-v3`
5. 保存配置

## 预计时间

- **首次构建**：15-30分钟（需要下载基础镜像）
- **增量构建**：5-15分钟（只构建变更部分）

## 注意事项

1. 构建过程中不要中断
2. 确保网络连接稳定
3. 如果构建失败，查看日志文件了解原因
