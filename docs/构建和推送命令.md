# Docker镜像构建和推送命令

## 完整流程

### 步骤1：设置代理（如果需要）

```bash
export https_proxy=http://127.0.0.1:7890
export http_proxy=http://127.0.0.1:7890
export all_proxy=socks5://127.0.0.1:7890
```

### 步骤2：构建镜像

```bash
cd /Users/zhouzeyong/Documents/GitHub/manga-image-translator

docker build --platform linux/amd64 -f Dockerfile.fc.optimized -t manga-image-translator:fc-optimized .
```

**说明：**
- `--platform linux/amd64`：指定平台为AMD64（FC需要）
- `-f Dockerfile.fc.optimized`：使用优化版Dockerfile
- `-t manga-image-translator:fc-optimized`：镜像名称和标签
- `.`：构建上下文（当前目录）

### 步骤3：标记镜像

```bash
docker tag manga-image-translator:fc-optimized \
  manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc-v3
```

**说明：**
- 将本地镜像标记为ACR镜像地址
- Tag使用 `fc-v3`（新版本）

### 步骤4：登录ACR（如果还没登录）

```bash
docker login --username=your-username manga-translator-registry.cn-hangzhou.cr.aliyuncs.com
```

**或者使用阿里云CLI：**
```bash
aliyun cr GetAuthorizationToken --region cn-hangzhou
```

### 步骤5：推送镜像到ACR

```bash
docker push manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc-v3
```

## 一键执行脚本

也可以创建一个脚本文件：

```bash
#!/bin/bash
set -e

# 设置代理
export https_proxy=http://127.0.0.1:7890
export http_proxy=http://127.0.0.1:7890
export all_proxy=socks5://127.0.0.1:7890

# 进入项目目录
cd /Users/zhouzeyong/Documents/GitHub/manga-image-translator

# 构建镜像
echo "开始构建镜像..."
docker build --platform linux/amd64 -f Dockerfile.fc.optimized -t manga-image-translator:fc-optimized .

# 标记镜像
echo "标记镜像..."
docker tag manga-image-translator:fc-optimized \
  manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc-v3

# 推送镜像
echo "推送镜像到ACR..."
docker push manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc-v3

echo "✅ 完成！"
```

## 验证镜像

构建完成后，可以验证：

```bash
# 查看本地镜像
docker images | grep manga-image-translator

# 查看镜像详情
docker inspect manga-image-translator:fc-optimized
```

## 注意事项

1. **构建时间**：首次构建可能需要15-30分钟
2. **网络**：确保网络连接稳定，可能需要代理
3. **磁盘空间**：确保有足够的磁盘空间（镜像约10GB+）
4. **ACR登录**：推送前需要登录ACR

## 如果构建失败

查看错误信息：
```bash
docker build --platform linux/amd64 -f Dockerfile.fc.optimized -t manga-image-translator:fc-optimized . 2>&1 | tee build.log
```

然后查看 `build.log` 文件了解错误原因。
