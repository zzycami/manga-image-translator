# FC GPU配额超限解决方案

## 错误信息

```json
{
    "RequestId": "1-6936437e-1550410f-0b47ec3bfe75",
    "Code": "ResourceExhausted",
    "Message": "Account's ondemand GPU usage of 'fc.gpu.ada.1' exceeded"
}
```

## 错误原因

**问题：** 账户的按需GPU使用量（`fc.gpu.ada.1`）已超过配额限制

**说明：**
- FC对GPU资源有配额限制
- 您的账户当前GPU配额已用完
- 需要申请增加配额或使用其他方案

## 解决方案

### 方案1：申请增加GPU配额（推荐）

#### 步骤1：进入配额中心

1. 登录阿里云控制台
2. 进入 **函数计算（FC）** 服务
3. 在左侧菜单找到 **"配额管理"** 或 **"配额中心"**
4. 或直接访问：https://quotas.console.aliyun.com/

#### 步骤2：查找GPU配额

1. 在配额中心，搜索 **"函数计算"** 或 **"FC"**
2. 查找与GPU相关的配额项：
   - `fc.gpu.ada.1` 按需GPU配额
   - GPU卡数上限
   - 弹性实例GPU配额

#### 步骤3：申请增加配额

1. 找到对应的配额项
2. 点击 **"申请"** 或 **"提升配额"**
3. 填写申请信息：
   - 申请原因：漫画翻译服务需要GPU加速
   - 申请数量：根据需求填写（如：2、4、8等）
   - 使用场景：AI图像处理和OCR识别
4. 提交申请
5. 等待审核（通常1-2个工作日）

### 方案2：使用常驻实例（如果已购买常驻资源池）

如果之前购买了常驻资源池：

1. 在函数配置中，将 **"实例类型"** 改为 **"常驻实例"**
2. 选择已购买的常驻资源池
3. 常驻实例不占用按需GPU配额

**注意：** 需要先购买常驻资源池

### 方案3：使用CPU实例（临时方案）

如果暂时无法增加GPU配额，可以：

1. 修改函数配置，不使用GPU
2. 使用CPU实例运行
3. 性能会较慢，但可以测试功能

**操作步骤：**
1. 在函数配置中，修改实例规格
2. 选择CPU实例（不使用GPU）
3. 重新部署函数

**缺点：**
- 性能较慢
- 不适合生产环境

### 方案4：联系阿里云支持

如果配额申请较慢，可以：

1. 联系阿里云技术支持
2. 说明业务需求
3. 请求紧急增加GPU配额

## 快速操作步骤

### 步骤1：申请增加GPU配额

1. 访问配额中心：https://quotas.console.aliyun.com/

2. 应该可以正常调用

## 注意事项

1. **GPU配额是账户级别的**
   - 所有函数共享配额
   - 需要合理规划使用

2. **常驻实例不占用按需配额**
   - 如果购买常驻资源池，可以使用常驻实例
   - 不占用按需GPU配额

3. **配额申请需要时间**
   - 通常1-2个工作日
   - 可以联系技术支持加急
