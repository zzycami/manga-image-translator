# RAM角色选择受信服务

## 当前状态

**当前选中：** "容器计算服务"（Container Computing Service）- ❌ **错误**

**需要选择：** "函数计算" 或 "函数计算 FC" - ✅ **正确**

## 操作步骤

### 步骤1：在下拉列表中查找"函数计算"

1. 下拉列表是按字母顺序排列的
2. 需要滚动查找，因为"函数计算"可能在列表的后面
3. 查找以下选项之一：
   - **"函数计算"** 或 **"函数计算 FC"**
   - 英文可能是：**"Function Compute"** 或 **"Function Compute FC"**

### 步骤2：选择"函数计算"

1. 在下拉列表中，找到 **"函数计算"** 或 **"函数计算 FC"**
2. 点击选择它
3. 选中的选项会显示一个 ✓ 标记

### 如果找不到"函数计算"

**可能的原因：**
- 列表很长，需要继续向下滚动
- 可能显示为英文名称："Function Compute"

**解决方法：**
1. 继续向下滚动下拉列表
2. 或者使用搜索功能（如果有）
3. 查找包含"函数"或"Function"的选项

## 常见选项位置

- ...（其他服务）
