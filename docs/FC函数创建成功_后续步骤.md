## 📋 下一步操作

### 步骤1：创建HTTP触发器

#### 1.1 进入函数详情页面

1. 在FC函数列表页面
2. 找到刚创建的函数：`manga-translator`
3. 点击函数名称进入详情页面

#### 1.2 创建HTTP触发器

1. 在函数详情页面，找到 **"触发器"** 或 **"HTTP触发器"** 标签
2. 点击 **"创建触发器"** 按钮
3. 配置触发器：
   - **触发方式**：HTTP触发器
   - **请求方法**：`GET,POST`（或根据需要选择）
   - **认证方式**：匿名访问（或根据需要配置）
   - **路径**：`/*`（或自定义路径，如 `/translate`）
4. 点击 **"创建"**

#### 1.3 获取函数访问地址

创建HTTP触发器后，会显示函数的访问地址，类似：
```
https://manga-translator-xxxxx.cn-hangzhou.fcapp.run
```

**记录这个地址，用于后续测试！**

## 🔧 常见问题排查

### 问题1：函数调用失败

**可能原因：**
- 镜像拉取失败
- 容器启动失败
- 代码执行错误

**解决方法：**
1. 查看函数日志
2. 检查镜像地址是否正确
3. 检查环境变量是否正确
4. 检查容器端口是否为9000

### 问题2：函数超时

**可能原因：**
- 翻译任务耗时过长
- 超时时间设置过短

**解决方法：**
1. 检查超时时间是否为600秒
2. 优化翻译流程
3. 增加超时时间（最大600秒）

### 问题3：无法访问DeepSeek API

**可能原因：**
- 环境变量未设置
- 网络配置问题

**解决方法：**
1. 检查环境变量是否正确
2. 检查"允许默认网卡访问公网"是否开启
3. 检查安全组规则
