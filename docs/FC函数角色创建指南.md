# FC函数角色创建指南

## 什么是函数角色？

函数角色是RAM（访问控制）角色，用于授权函数访问其他阿里云服务，如：
- 日志服务（SLS）
- 对象存储（OSS）
- 其他云服务

## 创建方式

### 方式1：在FC页面直接创建（推荐）

1. 在函数配置页面，找到 **"函数角色"** 部分
2. 点击 **"创建角色"** 按钮
3. FC会自动创建并配置角色
4. 选择刚创建的角色

**优点：**
- ✅ 简单快捷
- ✅ 自动配置权限
- ✅ 无需手动操作

### 方式2：在RAM控制台手动创建

如果FC页面没有"创建角色"按钮，需要手动创建：

#### 步骤1：登录RAM控制台

1. 登录阿里云控制台
2. 进入 **访问控制（RAM）** 服务
3. 点击左侧菜单 **身份管理** → **角色**

#### 步骤2：创建角色

1. 点击 **"创建角色"** 按钮
2. 选择 **"阿里云服务"**
3. 点击 **"下一步"**

#### 步骤3：配置角色

**角色名称：**
- 填写：`AliyunFCDefaultRole`（或自定义，如 `manga-translator-role`）

**受信服务：**
- 选择 **"函数计算"**
- 或选择 **"函数计算 FC"**

**描述：**
- 可选，填写：`漫画翻译服务函数角色`

#### 步骤4：配置权限策略

**基础权限：**
- 选择 **"AliyunLogFullAccess"**（日志服务完全访问权限）
- 如果需要访问OSS，选择 **"AliyunOSSFullAccess"**

**最小权限（推荐）：**
- 如果只需要日志功能，选择：
  - `AliyunLogFullAccess`（日志服务）

**完整权限（如果需要访问多种服务）：**
- `AliyunLogFullAccess`（日志服务）
- `AliyunOSSFullAccess`（对象存储）
- `AliyunVPCFullAccess`（如果需要VPC访问）

#### 步骤5：完成创建

1. 检查配置
2. 点击 **"完成"**
3. 角色创建成功

#### 步骤6：在FC中选择角色

1. 回到FC函数配置页面
2. 在 **"函数角色"** 下拉菜单中选择刚创建的角色
3. 或点击 **"刷新"** 按钮，然后选择角色

## 推荐配置

### 最小权限（推荐，适合初期测试）

**角色名称：** `manga-translator-role`

**权限策略：**
- `AliyunLogFullAccess`（日志服务）

**原因：**
- 只需要日志功能
- 最小权限原则，更安全
- 后续需要其他权限可以再添加

### 完整权限（如果需要访问多种服务）

**权限策略：**
- `AliyunLogFullAccess`（日志服务）
- `AliyunOSSFullAccess`（如果需要存储图片到OSS）
- `AliyunVPCFullAccess`（如果需要VPC访问）

## 快速操作步骤

### 如果FC页面有"创建角色"按钮：

1. 点击 **"创建角色"**
2. 选择默认权限（通常包括日志服务）
3. 确认创建
4. 选择刚创建的角色

### 如果FC页面没有"创建角色"按钮：

1. 打开新标签页，访问RAM控制台
2. 创建角色：
   - 类型：阿里云服务
   - 受信服务：函数计算
   - 角色名：`manga-translator-role`
   - 权限：`AliyunLogFullAccess`
3. 回到FC页面，点击 **"刷新"**
4. 选择刚创建的角色

## 注意事项

1. **角色名称**：可以自定义，建议使用有意义的名称
2. **权限策略**：遵循最小权限原则，只授予必要的权限
3. **受信服务**：必须选择"函数计算"，否则FC无法使用该角色
4. **后续修改**：可以在RAM控制台修改角色权限

## 如果暂时不需要访问其他服务

如果您的函数暂时不需要访问OSS、VPC等其他服务，只需要日志功能：

1. 创建角色时，只选择 `AliyunLogFullAccess`
2. 后续如果需要其他权限，可以在RAM控制台添加

## 总结

**推荐操作：**
1. 先尝试在FC页面点击 **"创建角色"**（最简单）
2. 如果没有，在RAM控制台手动创建
3. 选择最小权限：`AliyunLogFullAccess`
4. 在FC中选择刚创建的角色

**创建完成后，继续配置其他项（环境变量、日志等）。**
