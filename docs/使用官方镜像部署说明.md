# 使用官方镜像部署到阿里云FC

## 方案对比

### 方案1：基于官方镜像（推荐，如果官方镜像可用）

**优点：**
- ✅ 构建速度快（只需安装少量额外依赖）
- ✅ 已包含所有模型（约15GB）
- ✅ 依赖已预装

**缺点：**
- ❌ 镜像体积大（约15GB）
- ❌ 需要确认官方镜像是否包含 `fc_server.py`
- ❌ 如果官方镜像没有 `fc_server.py`，需要额外复制

### 方案2：从头构建（当前方案）

**优点：**
- ✅ 完全控制构建过程
- ✅ 可以优化镜像大小（不包含模型，从OSS加载）
- ✅ 可以自定义所有配置

**缺点：**
- ❌ 构建时间长（需要安装所有依赖）
- ❌ 需要处理模型下载（可以放到OSS）

## 使用官方镜像的步骤

### 步骤1：检查官方镜像是否包含 fc_server.py

```bash
# 拉取官方镜像
docker pull zyddnys/manga-image-translator:main

# 检查镜像内容
docker run --rm zyddnys/manga-image-translator:main ls -la /app/ | grep fc_server
```

### 步骤2A：如果官方镜像包含 fc_server.py

直接使用 `Dockerfile.fc.optimized`：

```bash
cd /Users/zhouzeyong/Documents/GitHub/manga-image-translator

# 构建镜像（基于官方镜像）
docker build --platform linux/amd64 -f Dockerfile.fc.optimized -t manga-image-translator:fc-optimized .
```

### 步骤2B：如果官方镜像不包含 fc_server.py

需要修改 `Dockerfile.fc.optimized`，添加复制步骤：

```dockerfile
FROM zyddnys/manga-image-translator:main

WORKDIR /app

# 复制 fc_server.py（如果官方镜像没有）
COPY fc_server.py /app/fc_server.py

# 安装FC HTTP服务器依赖
RUN pip install mangum uvicorn gunicorn --no-cache-dir

# ... 其余配置
```

### 步骤3：标记和推送镜像

```bash
# 标记镜像
docker tag manga-image-translator:fc-optimized \
  manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc

# 登录ACR
docker login --username=zzycami@foxmail.com manga-translator-registry.cn-hangzhou.cr.aliyuncs.com

# 推送镜像
docker push manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc
```

## 注意事项

1. **镜像大小**：官方镜像约15GB，推送和拉取都需要较长时间
2. **模型存储**：如果使用官方镜像，所有模型都在镜像中，FC冷启动会更快，但镜像体积大
3. **网络**：在中国大陆，从 Docker Hub 拉取官方镜像可能较慢，建议配置镜像加速器

## 推荐方案

**如果追求快速部署**：使用官方镜像（方案1）
**如果追求镜像优化**：使用当前方案（方案2），模型放在OSS上

## 检查官方镜像内容

运行以下命令检查官方镜像是否包含所需文件：

```bash
docker run --rm zyddnys/manga-image-translator:main \
  sh -c "ls -la /app/ | head -20 && echo '---' && python -c 'import manga_translator; print(manga_translator.__file__)'"
```
