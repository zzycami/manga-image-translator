# RAM角色创建详细步骤

## 当前页面：信任主体类型选择

### ⚠️ 重要：需要选择"云服务"

**当前状态：**
- ❌ "云账号"（Cloud Account）- 当前选中（错误）
- ✅ "云服务"（Cloud Service）- **需要选择这个**
- ❌ "身份提供商"（Identity Provider）

## 操作步骤

### 步骤1：选择信任主体类型

1. **点击"云服务"（Cloud Service）** 选项
   - 不要选择"云账号"
   - 不要选择"身份提供商"

2. **说明：**
   - "云服务"：允许指定的云服务（如函数计算）扮演这个角色
   - 这是FC函数角色需要的类型

### 步骤2：点击"确定"或"下一步"

选择"云服务"后，点击 **"确定"** 或 **"下一步"** 按钮

### 步骤3：配置云服务（下一步）

在下一步页面，需要：

1. **选择受信服务：**
   - 选择 **"函数计算"** 或 **"函数计算 FC"**

2. **角色名称：**
   - 填写：`manga-translator-role`（或自定义）

3. **描述：**
   - 可选，填写：`漫画翻译服务函数角色`

### 步骤4：配置权限策略

选择权限策略：
- **最小权限（推荐）**：`AliyunLogFullAccess`（日志服务）
- **如果需要OSS**：`AliyunOSSFullAccess`

### 步骤5：完成创建

1. 检查配置
2. 点击 **"完成"** 或 **"确定"**
3. 角色创建成功

## 关键点总结

| 步骤 | 选择 | 说明 |
|------|------|------|
| **信任主体类型** | **云服务** | 必须选择这个，不是"云账号" |
| **受信服务** | **函数计算** | 允许函数计算服务使用这个角色 |
| **权限策略** | `AliyunLogFullAccess` | 最小权限，日志服务 |

## 常见错误

❌ **错误：选择"云账号"**
- 这会让其他云账号使用这个角色
- FC函数无法使用这种类型的角色

✅ **正确：选择"云服务"**
- 允许云服务（函数计算）使用这个角色
- 这是FC函数角色需要的类型
