# 部署流程 - 方案1（基于官方镜像）

## 当前步骤：构建镜像

### 步骤1：构建镜像（进行中）

```bash
cd /Users/zhouzeyong/Documents/GitHub/manga-image-translator

# 构建镜像（基于官方镜像）
docker build --platform linux/amd64 -f Dockerfile.fc.optimized -t manga-image-translator:fc-optimized .
```

**预计时间：**
- 下载官方镜像（15GB）：10-30分钟（取决于网络速度）
- 安装额外依赖：2-5分钟
- **总计：15-35分钟**

**注意事项：**
- 首次构建需要下载约15GB的官方镜像
- 如果网络较慢，可以配置Docker镜像加速器
- 构建过程在后台运行，可以继续其他工作

### 步骤2：检查构建状态

```bash
# 查看构建进度
docker images | grep manga-image-translator

# 查看构建日志（如果构建失败）
docker build --platform linux/amd64 -f Dockerfile.fc.optimized -t manga-image-translator:fc-optimized . 2>&1 | tail -50
```

### 步骤3：标记镜像（构建完成后）

```bash
# 标记镜像为ACR格式
docker tag manga-image-translator:fc-optimized \
  manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc
```

### 步骤4：登录ACR

```bash
# 登录阿里云容器镜像服务
docker login --username=zzycami@foxmail.com manga-translator-registry.cn-hangzhou.cr.aliyuncs.com

# 输入密码（在ACR控制台获取）
```

### 步骤5：推送镜像

```bash
# 推送镜像到ACR（约15GB，需要时间）
docker push manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc
```

**预计时间：** 20-60分钟（取决于上传速度）

### 步骤6：在FC中创建函数

1. 登录阿里云控制台
2. 进入函数计算（FC）服务
3. 创建函数，选择"自定义容器"
4. 配置：
   - 镜像地址：`manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc`
   - 端口：`9000`
   - 内存：建议至少 `8192MB`（8GB）
   - GPU：选择GPU实例（如果需要）
   - 超时时间：`600秒`（10分钟）

## 常见问题

### Q1: 构建失败，提示网络错误
**A:** 配置Docker镜像加速器，或使用代理

### Q2: 推送镜像很慢
**A:** 这是正常的，15GB镜像需要时间。可以：
- 使用阿里云内网推送（如果在阿里云ECS上）
- 检查网络连接
- 使用多线程上传工具

### Q3: 镜像太大，FC启动慢
**A:** 这是使用官方镜像的权衡：
- 优点：冷启动快（模型已在镜像中）
- 缺点：镜像体积大

如果镜像太大，可以考虑方案2（从头构建，模型放OSS）
