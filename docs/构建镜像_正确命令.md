# 构建镜像 - 正确命令

## ✅ 已修复

- 移除了 Dockerfile 中的 `--platform`（Docker 建议只在命令行使用）
- 修复了 `.dockerignore` 排除 requirements.txt 的问题

## 构建命令

```bash
cd /Users/zhouzeyong/Documents/GitHub/manga-image-translator

# 构建镜像（必须在命令行指定平台）
docker build --platform linux/amd64 -f Dockerfile.fc -t manga-image-translator:fc .
```

**重要**：必须使用 `--platform linux/amd64` 参数，因为 FC 需要 AMD64 架构。

## 完整操作流程

### 步骤1：构建镜像

```bash
cd /Users/zhouzeyong/Documents/GitHub/manga-image-translator
docker build --platform linux/amd64 -f Dockerfile.fc -t manga-image-translator:fc .
```

**预计时间**：20-40 分钟（在 Mac M4 上构建 AMD64 镜像会较慢）

### 步骤2：标记镜像

```bash
docker tag manga-image-translator:fc \
  manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc
```

### 步骤3：登录 ACR

```bash
docker login --username=zzycami@foxmail.com manga-translator-registry.cn-hangzhou.cr.aliyuncs.com
# 输入您的 ACR 密码
```

### 步骤4：推送镜像

```bash
docker push manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc
```

## 关于构建速度

在 Mac M4 上构建 AMD64 镜像：
- 会使用 QEMU 模拟，速度较慢
- 这是正常的，镜像可以在 FC 上正常运行
- 预计需要 20-40 分钟

## 如果构建失败

如果遇到网络问题，可以：
1. 配置 Docker 镜像加速器（之前已说明）
2. 使用代理（如果有）
3. 重试构建（网络问题通常是临时的）
