## 📋 推送完成后的步骤

### 步骤1：在FC中更新镜像

1. 登录阿里云控制台
2. 进入 **函数计算（FC）** 服务
3. 找到函数：`manga-translator`
4. 点击函数名称进入详情页面
5. 点击 **"配置"**（Configuration）标签
6. 找到 **"修改镜像"** 或 **"镜像地址"**
7. 更新镜像Tag为：`fc-v5`
8. 点击 **"保存"** 或 **"更新"**
9. **等待几分钟**让新镜像生效
