# FC VPC配置确认方法

## 当前状态

- **专有网络（VPC）**：只有1个选项（已选择）
- **交换机（VSwitch）**：有2个选项，不确定选哪个
- **安全组（Security Group）**：有2个选项，不确定选哪个

## 需要确认的信息

### 1. ACR使用的VPC和交换机

需要确认ACR实例使用的：
- VPC ID
- 交换机ID
- 安全组ID（如果有）

## 确认方法

### 方法1：在ACR控制台查看（推荐）

#### 步骤1：登录ACR控制台

1. 登录阿里云控制台
2. 进入 **容器镜像服务（ACR）**
3. 找到您的ACR实例：`manga-translator-registry`

#### 步骤2：查看网络配置

在ACR实例详情页面，查看：
- **基本信息** → **网络类型** 或 **VPC配置**
- **网络配置** 或 **网络设置**
- 记录：
  - VPC ID
  - 交换机ID
  - 安全组ID（如果有）

#### 步骤3：对比FC中的选项

1. 确认ACR的VPC ID是否与FC中的VPC ID一致
2. 确认ACR的交换机ID是否在FC的交换机选项中
3. 如果一致，选择对应的选项

### 方法2：查看ACR实例的网络信息

在ACR控制台：
1. 找到实例：`manga-translator-registry`
2. 点击实例名称进入详情
3. 查看 **"网络配置"** 或 **"基本信息"**
4. 查找VPC相关信息

### 方法3：如果ACR在默认VPC中

如果ACR在默认VPC中：
1. 在FC中选择默认VPC（应该已经选中）
2. 选择默认交换机（通常是第一个）
3. 选择默认安全组（通常是第一个）

## 选择建议

### 专有网络（VPC）

**选择：** 唯一的那个选项（应该已经选中）

**原因：**
- 如果只有一个选项，通常就是默认VPC
- ACR很可能也在同一个VPC中

### 交换机（VSwitch）

**选择方法：**

1. **先查看ACR的交换机ID**
   - 在ACR控制台查看
   - 记录交换机ID

2. **在FC中选择对应的交换机**
   - 如果ACR的交换机ID在选项中，选择它
   - 如果不在，选择同VPC下的任意交换机（通常也可以工作）

3. **如果无法确认，选择第一个**
   - 通常是默认交换机
   - 同VPC下的交换机通常可以互通

**两个选项对比：**
- `vsw-bp1wbf4ozrjzwwgtcazuf` - 可用区 I，IP范围：172.31.192.0/20
- `vsw-bp1rxac5vijrcbdjziza4` - 可用区 H，IP范围：172.27.192.0/20

**建议：** 先选择第一个（可用区 I），如果不行再换第二个

### 安全组（Security Group）

**选择方法：**

1. **查看ACR的安全组（如果有）**
   - 在ACR控制台查看
   - 记录安全组ID

2. **在FC中选择安全组**
   - 如果ACR有安全组，选择相同的
   - 如果没有，选择任意一个都可以

3. **如果无法确认，选择第一个**
   - 通常是默认安全组
   - 后续可以调整安全组规则

**两个选项：**
- `sg-xiaoyujun` / `sg-bp1bqkbjb8nnlr4h1y2m`
- `sg-bp1dmqfq0y1me56v99p2`

**建议：** 先选择第一个，后续如果需要再调整

## 快速操作步骤

### 步骤1：查看ACR的网络配置

1. 打开新标签页
2. 登录阿里云控制台
3. 进入 **容器镜像服务（ACR）**
4. 找到实例：`manga-translator-registry`
5. 查看网络配置，记录：
   - VPC ID
   - 交换机ID
   - 安全组ID（如果有）

### 步骤2：在FC中选择对应选项

1. 回到FC函数配置页面
2. **VPC**：确认已选择（应该只有一个选项）
3. **交换机**：选择与ACR相同的交换机ID
4. **安全组**：选择与ACR相同的安全组ID（如果有），或选择第一个

### 步骤3：配置安全组规则

选择安全组后，需要确保安全组规则允许：
- 函数访问ACR（443端口）
- 函数访问公网（用于DeepSeek API）

## 如果无法确认ACR的网络配置

### 方案1：使用默认配置

1. **VPC**：选择唯一的选项（已选中）
2. **交换机**：选择第一个（通常是默认交换机）
3. **安全组**：选择第一个（通常是默认安全组）

### 方案2：联系ACR支持

如果无法确定，可以：
1. 联系ACR技术支持
2. 询问ACR实例的网络配置
3. 获取VPC ID和交换机ID

## 注意事项

1. **同VPC下的交换机可以互通**
   - 即使选择不同的交换机，通常也可以访问ACR
   - 但可能会有1-2ms的延迟

2. **安全组规则很重要**
   - 选择安全组后，需要确保规则允许访问ACR和公网
   - 可以在安全组中配置规则

3. **可以先尝试创建**
   - 如果配置不对，函数创建会失败或无法拉取镜像
   - 可以根据错误信息调整

## 推荐操作

### 快速方案（如果无法确认ACR配置）

1. **VPC**：选择唯一的选项（已选中）
2. **交换机**：选择第一个 `vsw-bp1wbf4ozrjzwwgtcazuf`（可用区 I）
3. **安全组**：选择第一个 `sg-xiaoyujun` / `sg-bp1bqkbjb8nnlr4h1y2m`

### 精确方案（推荐）

1. **先查看ACR的网络配置**
2. **选择与ACR相同的VPC、交换机、安全组**
3. **配置安全组规则**
