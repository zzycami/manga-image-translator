# FC实例预热说明

## 什么是实例预热？

实例预热是在函数实例启动成功之后、处理请求之前，通过运行指定脚本或调用接口，进行模型加载等操作，从而优化冷启动。

## 对于漫画翻译服务的影响

### 我们的服务需要加载：
- OCR模型（文字识别）
- 图像处理模型
- 翻译服务连接
- 其他依赖资源

### 如果不开启预热：
- ❌ 第一次请求需要加载模型，响应时间较长（可能30秒-2分钟）
- ❌ 用户体验不好
- ✅ 配置简单

### 如果开启预热：
- ✅ 实例启动时就加载好模型
- ✅ 第一次请求就能快速响应（秒级）
- ✅ 用户体验好
- ❌ 需要配置预热脚本
- ❌ 实例启动时间可能稍长

## 建议

### 方案1：先不开启（推荐初期测试）

**原因：**
1. 先验证基本功能是否正常
2. 避免配置复杂度
3. 可以后续再优化

**操作：**
- 保持关闭状态（默认）

### 方案2：开启预热（推荐生产环境）

**原因：**
1. 显著改善用户体验
2. 减少首次请求延迟
3. 适合生产环境

**需要配置：**
- 预热脚本或接口
- 例如：调用 `/health` 接口或运行模型加载脚本

## 预热配置方法

如果选择开启，需要配置：

### 方法1：调用健康检查接口

**预热命令：**
```bash
curl http://localhost:9000/health
```

**或使用Python脚本：**
```python
import requests
requests.get('http://localhost:9000/health', timeout=300)
```

### 方法2：调用初始化接口（如果有）

如果 `fc_server.py` 有初始化接口，可以调用它来加载模型。

## 最终建议

### 初期测试阶段：**不开启**

**原因：**
- 先验证基本功能
- 避免配置复杂度
- 可以快速测试

### 生产环境：**开启**

**原因：**
- 改善用户体验
- 减少冷启动延迟
- 提升服务质量
