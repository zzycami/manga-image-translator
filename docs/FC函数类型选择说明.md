# FC函数类型选择说明

## 函数类型对比

### 1. 事件函数 (Event Function)
- **适用场景**：事件驱动的任务（OSS触发器、Kafka触发器、SLS触发器）
- **不适合**：需要HTTP API接口的场景

### 2. Web 函数 (Web Function) ⭐ **推荐**
- **适用场景**：
  - HTTP API服务
  - Web应用
  - 长时间运行的任务
  - 需要自定义HTTP响应的场景
- **特点**：
  - 支持HTTP触发器
  - 可以处理HTTP请求和响应
  - 支持自定义容器镜像
  - 可以配置GPU资源
- **✅ 适合我们的漫画翻译服务**

### 3. 任务函数 (Task Function)
- **适用场景**：异步任务处理
- **不适合**：需要同步HTTP响应的场景

### 4. GPU 函数 (GPU Function)
- **适用场景**：需要GPU加速的计算任务
- **注意**：如果选择这个，后续配置中也需要确保支持HTTP接口

## 推荐选择：Web 函数

**原因：**
1. ✅ 我们的服务需要通过HTTP接口提供翻译功能
2. ✅ 支持自定义容器镜像（我们使用的是容器镜像）
3. ✅ 可以配置GPU资源（如果需要）
4. ✅ 支持长时间运行（翻译任务可能需要几分钟）
5. ✅ 可以处理HTTP请求和响应

## 操作步骤

1. 在弹窗中，点击 **"Web 函数"** 标签
2. 查看Web函数的说明
3. 点击 **"创建 Web 函数"** 按钮
4. 继续配置函数（镜像、端口、环境变量等）

## 后续配置

选择Web函数后，在配置页面：
- 选择 **"使用容器镜像创建"**
- 配置镜像地址、端口（9000）、内存、GPU等
- 创建HTTP触发器
