# FC启动命令和端口配置

## 配置说明

### 1. 启动命令

**填写：留空**（不填写任何内容）

**原因：**
- 我们的Docker镜像已经配置了默认的CMD
- 镜像中的CMD是：`gunicorn fc_server:app -k uvicorn.workers.UvicornWorker -b 0.0.0.0:9000 --timeout 600`
- 如果留空，FC会使用镜像的默认CMD

**如果必须填写，可以填写：**
```
gunicorn fc_server:app -k uvicorn.workers.UvicornWorker -b 0.0.0.0:9000 --timeout 600
```

但建议留空，使用镜像默认配置。

### 2. 监听端口 ⚠️ **必须填写**

**填写：`9000`**

**原因：**
- 我们的 `fc_server.py` 监听在 9000 端口
- 镜像的CMD中已经配置了 `-b 0.0.0.0:9000`
- FC需要知道容器监听的端口，才能正确转发请求

### 3. 执行超时时间 ⚠️ **需要修改**

**填写：`600`**（单位：秒）

**原因：**
- 翻译一张漫画图片可能需要几分钟
- 包括：OCR识别、翻译、图像处理、渲染等步骤
- 默认的60秒可能不够，需要设置为600秒（10分钟）

**注意：**
- FC的最大超时时间是600秒（10分钟）
- 如果任务超过10分钟，可能需要优化处理流程或分批处理

## 配置总结

| 配置项 | 填写值 | 说明 |
|--------|--------|------|
| **启动命令** | 留空 | 使用镜像默认CMD |
| **监听端口** | `9000` | fc_server.py监听的端口 |
| **执行超时时间** | `600` | 10分钟，足够翻译任务完成 |

## 验证配置

配置完成后，确认：
- ✅ 启动命令：留空（或填写完整的gunicorn命令）
- ✅ 监听端口：`9000`
- ✅ 执行超时时间：`600`秒
