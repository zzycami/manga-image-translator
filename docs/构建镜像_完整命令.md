# 构建镜像 - 完整命令步骤

## 问题说明

构建失败是因为访问 Docker Hub 网络不稳定。可以使用以下方案解决。

---

## 方案1：配置 Docker 镜像加速器（推荐）

### 1.1 配置镜像加速器

**macOS（Docker Desktop）**：
1. 打开 Docker Desktop
2. 点击设置（Settings/Preferences）
3. 选择 "Docker Engine"
4. 在 JSON 配置中添加：

```json
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com",
    "https://mirror.baidubce.com"
  ]
}
```

5. 点击 "Apply & Restart"

### 1.2 构建镜像

```bash
cd /Users/zhouzeyong/Documents/GitHub/manga-image-translator
docker build -f Dockerfile.fc -t manga-image-translator:fc .
```

---

## 方案2：使用国内镜像源（如果方案1不行）

修改 Dockerfile，使用国内镜像源。我可以帮您创建一个修改版的 Dockerfile。

## 完整操作命令（按顺序执行）

### 步骤1：构建镜像

```bash
# 进入项目目录
cd /Users/zhouzeyong/Documents/GitHub/manga-image-translator

# 构建镜像（配置镜像加速器后执行）
docker build -f Dockerfile.fc -t manga-image-translator:fc .
```

**如果还是失败**，可以尝试：
```bash
# 使用代理（如果您有代理）
export HTTP_PROXY=http://your-proxy:port
export HTTPS_PROXY=http://your-proxy:port
docker build -f Dockerfile.fc -t manga-image-translator:fc .
```

---

### 步骤2：标记镜像

构建成功后，执行：

```bash
docker tag manga-image-translator:fc \
  manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc
```

---

### 步骤3：登录 ACR

```bash
docker login --username=zzycami@foxmail.com manga-translator-registry.cn-hangzhou.cr.aliyuncs.com
```

然后输入您的 ACR 密码。

---

### 步骤4：推送镜像

```bash
docker push manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc
```

---

## 快速检查

构建完成后，检查镜像：

```bash
docker images | grep manga-image-translator
```

应该能看到：
```
manga-image-translator:fc
manga-translator-registry.cn-hangzhou.cr.aliyuncs.com/manga-translator/manga-image-translator:fc
```
