# FC企业版ACR VPC配置说明

## 错误原因

**错误信息：** "使用企业版 ACR 时，您需要在函数的"网络配置"中为函数配置可访问 ACR 实例的 VPC。"

**原因：**
- 企业版ACR实例可能配置在VPC中
- 函数需要访问VPC内的ACR才能拉取镜像
- 需要在函数的网络配置中启用VPC访问

## 解决方案

### 方案1：配置VPC访问ACR（推荐）

#### 步骤1：查看ACR的VPC配置

1. 登录阿里云控制台
2. 进入 **容器镜像服务（ACR）**
3. 找到您的ACR实例：`manga-translator-registry`
4. 查看实例的网络配置：
   - 是否在VPC中？
   - VPC ID是什么？
   - 交换机ID是什么？

#### 步骤2：在FC函数中配置VPC

1. 回到FC函数配置页面
2. 展开 **"高级配置"** → **"网络"** 部分
3. 勾选 **"允许访问 VPC"**
4. 配置VPC信息：
   - **VPC**：选择ACR实例所在的VPC
   - **交换机**：选择ACR实例所在的交换机（或同VPC下的交换机）
   - **安全组**：选择或创建安全组

#### 步骤3：配置安全组规则

确保安全组允许：
- 函数访问ACR（通常是443端口）
- 函数访问公网（用于访问DeepSeek API）

### 方案2：配置ACR公网访问（如果支持）

如果ACR支持公网访问：

1. 在ACR控制台
2. 找到您的ACR实例
3. 查看是否有"公网访问"选项
4. 如果支持，开启公网访问
5. 这样函数就可以通过公网访问ACR，不需要VPC

**注意：** 企业版ACR可能不支持公网访问，需要检查ACR的配置。

### 方案3：使用Docker Hub（临时方案）

如果VPC配置复杂，可以临时使用Docker Hub：

1. 推送镜像到Docker Hub
2. 在FC中选择"使用自定义仓库中的镜像"
3. 填写Docker Hub镜像地址

## 详细配置步骤（方案1）

### 步骤1：查看ACR的VPC信息

1. 登录阿里云控制台
2. 进入 **容器镜像服务（ACR）**
3. 找到实例：`manga-translator-registry`
4. 查看 **"网络配置"** 或 **"基本信息"**
5. 记录：
   - VPC ID
   - 交换机ID
   - 安全组ID（如果有）

### 步骤2：在FC函数中配置VPC

1. 回到FC函数配置页面
2. 展开 **"高级配置"** → **"网络"** 部分
3. 勾选 **"允许访问 VPC"**
4. 配置：
   - **VPC**：选择ACR实例所在的VPC
   - **交换机**：选择ACR实例所在的交换机
   - **安全组**：选择或创建安全组

### 步骤3：配置安全组规则

**入站规则：**
- 允许函数访问ACR（443端口）

**出站规则：**
- 允许访问公网（用于DeepSeek API）
- 允许访问ACR（443端口）

### 步骤4：重新创建函数

配置完VPC后，重新创建函数。

## 如果找不到ACR的VPC信息

### 方法1：联系ACR支持

如果无法确定ACR的VPC配置，可以：
1. 联系ACR技术支持
2. 询问ACR实例的网络配置
3. 获取VPC ID和交换机ID

### 方法2：检查ACR控制台

在ACR控制台：
1. 找到您的ACR实例
2. 查看 **"网络配置"** 或 **"基本信息"**
3. 查看是否有VPC相关信息

### 方法3：使用默认VPC

如果ACR在默认VPC中：
1. 在FC中选择默认VPC
2. 选择默认交换机
3. 配置安全组

## 注意事项

1. **VPC配置后，函数仍可访问公网**
   - 需要确保安全组允许出站访问公网
   - 用于访问DeepSeek API

2. **VPC配置可能增加冷启动时间**
   - VPC网络初始化需要时间
   - 但这是必要的，因为需要访问ACR

3. **安全组配置很重要**
   - 确保允许函数访问ACR
   - 确保允许函数访问公网

## 快速操作步骤

1. **查看ACR的VPC配置**
   - ACR控制台 → 实例详情 → 网络配置

2. **在FC函数中配置VPC**
   - 高级配置 → 网络 → 允许访问 VPC
   - 选择ACR所在的VPC和交换机
   - 配置安全组

3. **配置安全组规则**
   - 允许访问ACR（443端口）
   - 允许访问公网

4. **重新创建函数**

## 总结

**必须配置VPC访问，因为：**
- 企业版ACR在VPC中
- 函数需要访问VPC内的ACR才能拉取镜像

**配置步骤：**
1. 查看ACR的VPC信息
2. 在FC函数中启用VPC访问
3. 配置VPC、交换机、安全组
4. 重新创建函数
