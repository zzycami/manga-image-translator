## 关于平台问题

**为什么需要 AMD64？**
- 阿里云 FC 的 GPU 实例使用 AMD64（x86_64）架构
- Mac M4 是 ARM64 架构
- 需要在 Mac 上构建 AMD64 镜像，Docker 会自动使用模拟（QEMU）

**性能影响**：
- 构建速度会较慢（模拟执行）
- 但这是正常的，镜像可以在 FC 上正常运行

## 如果构建还是失败

如果 `requirements.txt` 还是找不到，可以检查：

```bash
# 确认文件存在
ls -la requirements.txt

# 确认在正确的目录
pwd
```

如果文件存在但还是报错，可能是 `.dockerignore` 排除了它，可以检查：

```bash
cat .dockerignore
```
